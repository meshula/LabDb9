# Sanskrit MacGuffins (संस्कृत मैकगफिन)

## Overview
Testing Unicode normalization with Sanskrit terms and consciousness concepts.

## Sanskrit Terms

### स्वभाव (Svabhāva)
- **Meaning**: Essential nature, intrinsic being
- **IAST**: svabhāva
- **ASCII**: svabhava
- **Context**: Fundamental consciousness concept

### लक्षण (Lakṣaṇa)
- **Meaning**: Characteristic mark, defining sign
- **IAST**: lakṣaṇa
- **ASCII**: lakshana
- **Context**: Manifestation of essence

### करित्र (Karitra)
- **Meaning**: Function, activity, operational capacity
- **IAST**: karitra
- **ASCII**: karitra
- **Context**: Instrumental witnessing activity

## Unicode Test Patterns

Testing case folding:
- SVABHĀVA → svabhāva → svabhava
- LAKṢAṆA → lakṣaṇa → lakshana
- KARITRA → karitra → karitra
